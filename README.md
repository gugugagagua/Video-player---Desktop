# 视频集播放器（Windows 桌面版）
#该软件由AI辅助完成

**当前版本：1.2.0**

> Android 版见另一仓库 [https://github.com/gugugagagua/Video-player]

## 技术栈

- Python 3.10+ / PyQt6（Qt 6）
- PyQt6.QtMultimedia（FFmpeg 后端，视频播放）
- OpenCV-Python（首帧提取、时长探测、进度条悬停抽帧）
- Pillow（封面图片格式转换）
- SQLite3（Python 内置，数据持久化）
- PyQt6.QtSvg（运行时绘制可着色的 Material 图标）
- PyInstaller + Inno Setup（打包与安装包）

## 功能对照

| Android 版功能 | 桌面版实现 |
|---------------|-----------|
| 导入文件夹生成视频集 | 文件菜单 / 首页「导入视频集」选择文件夹 → `os.scandir` 扫描视频 |
| 视频集封面（cover.png / 首帧） | 右键「设置封面（从本地图片）」或「提取首帧为封面」，统一保存为视频集根目录 `cover.png` |
| 分组管理（新建 / 重命名 / 删除 / 移动） | 分组显示为**文件夹卡片**，点击**逐层进入**，右键可重命名 / 设置封面 / 删除 |
| 分组封面 | 从组内任一视频集的封面中选择 |
| 播放列表、上一集 / 下一集 | 播放页右侧边栏 + 底部控制栏 |
| 播放进度记忆（续播） | `collections.last_video_id` + `videos.last_position`，退出 / 返回首页 / 切集时保存 |
| 观看进度可视化 | 视频集封面角标「看到 N/M 集」+ 进度条；播放列表每集显示已看 / 未看与进度条 |
| 搜索 | 顶栏搜索框，匹配视频集名称与视频文件名，视频结果可直接跳转播放 |
| 播放控制 | 播放/暂停、进度拖拽、上下集、倍速、全屏 |
| 快进 | 短按 `→` 快进 10 秒；长按 `D` / `→` 加速 2 倍速，松手恢复 |
| 滑动调进度 | 拖动进度条调进度，**鼠标悬停进度条**即弹出目标画面与时间预览 |
| 全屏 | `F` 键或双击画面切换，`Esc` 退出 |
| 深 / 浅色主题 | Material 3，**自动跟随系统**颜色模式，菜单「主题」可手动切换 |
| 音量 | 底部音量滑块 + 上下方向键微调 |

## 下载与安装

前往 [Releases](../../releases) 页面下载最新版本：

| 下载 | 说明 |
|---|---|
| **`Video-Set-Player.exe`** | 安装版（推荐），默认安装到 `C:\Program Files\视频集播放器` |
| **`Video-Set-Player.zip`** | 免安装便携版，解压即用 |

**安装版**：双击运行，按向导完成安装，然后从开始菜单或桌面快捷方式启动。

**便携版**：解压后运行 `Video-Set-Player\Video Set Player.exe`。（`_internal\` 目录必须与 exe 放在一起，不可单独移动 exe）

**系统要求：Windows 10 64 位及以上。**

## 构建

### 源码运行

```powershell
pip install -r requirements.txt
python main.py
```

### 打包为免安装程序

```
build.bat
```

产物位于 `dist\视频集播放器\`（目录模式，非单文件）。

### 制作安装包

需先安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)，然后：

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

产物位于 `installer_output\`。修改应用名 / 版本号只需改 `installer.iss` 顶部的 `#define`。

## 使用说明

### 媒体库目录（推荐）

每个**视频集 = 一个文件夹**，把视频按以下层级放置：

```
任意位置/
├── 电视剧A/          ← 自动成为一个视频集
│   ├── cover.png     ← 可选，作为封面
│   ├── --01.mp4
│   └── --02.mp4
├── 纪录片B/          ← 另一个视频集
│   └── ...
```

- 支持的视频格式：`mp4 / avi / mkv / mov / wmv / flv / webm / m4v / mpg / mpeg / 3gp`
- 文件按**自然排序**排列：`--1` → `--2` → `--10`（而不是字典序的 `--1` → `--10` → `--2`）
- 扫描为**单层**：文件夹内的视频即该视频集的内容，不再递归更深层级

### 导入视频集

两种方式：

- 首页底部 **「+ 导入视频集」** 按钮
- 菜单栏 **文件 → 导入视频集**

选择文件夹后自动扫描入库。若该文件夹已导入，会按当前文件重新排序（可直接用来自动同步新增 / 删除的文件）。

### 分组与视频集

- 首页根层：分组显示为**文件夹卡片**，与未分组的视频集混排
- 点击文件夹**进入该分组**，顶部显示「← 返回全部 / 分组名」面包屑
- **右键分组**：重命名 / 设置分组封面 / 删除（组内视频集不会被删除）
- **右键视频集**：重命名 / 设置封面 / 提取首帧 / 新建分组（移入此集）/ 移动到分组 / 移出分组 / 删除
- **拖拽卡片**可自由排序，顺序写入数据库长期保存

### 封面

每个视频集最多只有一个 `cover.png`，保存在视频集文件夹根目录：

| 方式 | 说明 |
|---|---|
| 设置封面（从本地图片） | 选择 png / jpg / jpeg / bmp / gif，转成 `cover.png` 存入视频集文件夹 |
| 提取首帧为封面 | 取第一集的首帧，**按原分辨率**保存为 `cover.png` |

> 封面不自动生成，需要手动选择其中一种方式。竖版海报与横版截图都会等比缩放居中显示，不会拉伸变形。

### 搜索

在顶栏搜索框输入关键字：

- **视频集**：按名称实时过滤，以卡片形式展示
- **视频**：按文件名模糊匹配（如输入「第05集」），点击结果**直接跳转到该集播放**

### 观看进度

- 视频集卡片左下角显示状态角标：`看到 N/M 集` / `✓ 已看完` / `未看 0/N 集`，封面底部有整体进度条
- 播放列表每集显示状态图标与单集进度条：正在播放 / 已看完 / 看到 mm:ss / 未看
- 打开视频集时自动用 OpenCV 补全缺失时长，使进度百分比准确
- **打开视频集会自动跳转到上次观看的那一集并续播**；进度在「退出程序 / 返回首页 / 切换到其他集」时保存（忽略小于 3 秒的零碎进度）

### 播放操作

| 操作 | 说明 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← | 快退 10 秒 |
| → | 短按快进 10 秒 |
| 长按 D / → | 2 倍速播放，松手恢复（顶部显示 `»2x` 提示） |
| ↑ / ↓ | 音量 +5 / -5 |
| F | 切换全屏 |
| Esc | 退出全屏（全屏时按 Esc 不会直接返回首页） |
| 双击画面 | 切换全屏 |
| 拖动进度条 | 调整进度，**悬停进度条可预览目标画面与时间** |
| 倍速按钮 | 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x |

> **进度预览窗**：鼠标悬停在进度条上会弹出小预览窗——上方是**目标位置的画面**，下方显示目标时间。抽帧按 120ms 节流，并对视频句柄做 LRU 缓存（最多 4 个），拖动依然流畅。
>
> 在搜索框内输入时，播放快捷键会自动禁用，避免冲突。

播放结束后自动播放下一集；遇到无法播放的视频会给出明确提示。

### 主题与音频

- **主题**：启动时自动检测系统颜色模式并应用 Material 3 深 / 浅色方案；菜单「主题 → 深色模式 / 浅色模式」可手动切换
- **音频**：菜单「音频」列出系统所有音频输出设备，可随时切换（如扬声器 / 耳机 / 蓝牙）

## 数据存储

- 数据库：`data/videos.db`（SQLite，含 `groups` / `collections` / `videos` 三张表）
- 封面：视频集文件夹内的 `cover.png`
- 视频文件**不做拷贝**，数据库保存原始文件路径

## 已知限制

- 目录扫描为**单层**：视频集就是所选文件夹本身，不递归子目录
- 每个视频集的封面固定为唯一的 `cover.png`
- 播放依赖 QtMultimedia 的 FFmpeg 后端，个别编码格式可能无法解码
- 安装包体积较大（PyQt6 + OpenCV，约 67 MB）
